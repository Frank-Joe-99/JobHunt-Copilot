## M08：模型能以已配置的可靠格式返回结果

实现位于 [LLM 客户端](../tools/llm_client.py)和[格式/能力缓存](../tools/llm_formats.py)，详见 [M08 说明](M08-STRUCTURED-OUTPUT.md)。

- 显式验证支持、且业务 schema 可严格表示时使用原生 JSON Schema；否则按配置使用 JSON mode 或提示词 JSON。
- 保留全部业务字段验证。动态字典在 auto 模式采用兼容格式；无效 schema、鉴权、拒绝和截断不会被自动降级掩盖。
- 仅明确“不支持该输出格式”的能力错误触发降级。缓存按端点、模型和能力版本失效，支持 TTL 和显式关闭，不保存正文或密钥。

## M09：给模型有限、可审查的面试决策空间

实现位于 [adaptive.py](../skills/mock_interviewer/adaptive.py)、[共用服务](../core/interview_service.py)和[存储](../skills/mock_interviewer/session_store.py)。

一轮通常一次调用，返回动作和问题，不在实时路径串联多次评审。模型可以澄清、追问或进入下一阶段；程序决定允许动作、覆盖顺序、连续追问上限、轮数、有效时长与请求预算。重复问题、非法阶段和过早结束不会提交为新状态。

充分回答可以立即进入下一阶段，不必问满追问上限。最后反问先回应再结束。模拟保持考官视角；训练允许提示与重答，原回答保留，复盘明确区分工具帮助和候选人事实。

自适应先完成结构和业务校验，再原子保存，随后返回正文，避免展示后断连导致不必要的重新生成。它不展示未校验的 JSON 片段，因此等待首个正文的体验与原流式模式不同。固定阶段原流程保留，用户可新建 fixed 会话回退。

### 入口

```powershell
uv run jobhunt interview --flow adaptive --company 示例企业 --target-role 前端开发 --mode practice
uv run jobhunt interview --resume-session <session_id>
uv run jobhunt interview-sessions show <session_id>
uv run jobhunt interview-sessions compare <fixed_id> --with-session <adaptive_id>
```

默认自适应上限：16 个交互轮数、1800 秒有效面试时间、连续追问 2 次、每轮 1 次 HTTP 请求、整场问答 32 次请求、每轮生成 30 秒。暂停时间不计入有效时长；复盘请求另计。调整参数及公平比较方法见 [M09 试验说明](M09-EVALUATION.md)。

MCP 在原 start 工具增加可选 flow 和预算参数，不增加工具数量；answer 增加 flow、结束原因、策略提示和统计。旧调用不需要补参数，恢复继续沿用保存的流程与策略。

### 持久指标和迁移

会话库 v2 对精确匹配的 v1 表增加 `metrics_json`，迁移在短事务中进行，不重写档案快照与历史。旧会话缺少新字段时按 fixed 加载，旧指标保持“未测量”。错误结构或未知版本会拒绝，不影响投递数据库。

保存已知模型请求次数、生成失败率、重试次数、服务耗时和可读文本就绪延迟；重复结果回放不增加计数。崩溃遗留的远端请求无法确知时记录保守上界，并计入请求预算，而不冒充实测次数。

离线比较器核对输入、模型身份与共有预算，并展示统计，不自动给质量评分。它不能验证端点背后的实际模型修订或模型设置是否被人为更改；运行成对试验时需保持配置一致。

主要覆盖：

- 原生 schema 格式、严格错误分类、缓存命中及失效、共享预算和超时/超体积响应。
- 拒绝与截断不入正式结果，字段修复保留状态，错误不泄露生成正文。
- 澄清、可选追问、强制阶段覆盖、重复问题、非法跳跃、训练提示和重答。
- 反问在提问轮数上限仍先回应；全局轮数、有效时长和请求预算停止；暂停不计时。
- 流程重试、缓存回放、调用计数、未知请求上界与失败率；展示前原子保存和迟到结果拒绝。
- 真实客户端配合模拟 HTTP 走原生 schema，验证业务状态原子性。
- v1→v2 数据保留、迁移失败回滚、旧会话默认流程，以及 CLI 与 MCP 跨进程恢复。
- 原有简历、GitHub 推荐、雷达、投递看板、业务模块隔离及 MCP 协议测试继续通过。

应用测试使用合成档案、临时数据库、离线替身和模拟 HTTP，没有读取真实个人配置、请求真实模型或 GitHub，也没有提交 storage 或个人产物。
