# pseudo job for test
公司：腾讯
职位：Web 前端开发工程师
工作地点：深圳
部门：互动娱乐事业群 (IEG)

岗位职责：
1. 负责腾讯游戏运营活动平台与 Web 端核心用户界面的研发与体验优化；
2. 负责前端工程化架构、首屏秒开性能优化与微前端模块拆分；
3. 与 UI 设计师、产品经理紧密合作，交付极高完成度的互动视觉体验。

岗位要求：
1. 本科及以上学历，熟悉 W3C 标准，精通 HTML5/CSS3/JavaScript (ES6+)；
2. 熟练掌握 Vue3 或 React 现代前端框架，理解响应式原理与状态管理工具（Pinia/Redux）；
3. 熟练掌握 Webpack/Vite 现代前端构建工具链与打包产物优化；
4. 熟悉跨端适配、CSS 动效设计与移动端 H5 性能调优；
5. 热爱游戏与前端交互，具备良好的审美与同理心。

加分项：
1. 熟悉 TypeScript 并有生产环境大型前端项目经验者优先；
2. 熟悉 WebGL / Canvas / Three.js 3D 图形渲染技术者优先。
