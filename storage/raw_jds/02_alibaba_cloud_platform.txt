# pseudo job for test
公司：阿里巴巴
职位：云原生开发工程师 - PaaS平台
工作地点：杭州
部门：阿里云智能-云原生架构组

岗位职责：
1. 负责阿里云核心容器调度平台与云原生微服务中台的设计与开发；
2. 建设大规模分布式消息流系统，支撑双十一海量并发消息消费与低延迟解耦；
3. 负责集群弹性伸缩策略与监控可观测性建设。

岗位要求：
1. 计算机或软件工程相关专业本科及以上学历；
2. 熟练掌握 Go 语言开发，熟悉高并发 goroutine 调度模型与并发通信；
3. 熟悉 Apache Kafka 或 RocketMQ 等分布式消息中间件架构，理解消息持久化与消费堆积排查；
4. 熟练掌握 Docker 容器化技术与 Kubernetes (K8s) 基本运维与调度原理；
5. 具备扎实的排错分析能力与团队协作意识。

加分项：
1. 有云原生开源社区 (如 CNCF 旗下项目) 贡献经历者优先；
2. 有大型生产环境微服务治理实操经验者优先。
