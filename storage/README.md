# 📦 storage/ 目录：产物持久化仓库

`storage/` 目录专门用于存放 JobHunt-Copilot 系统运行过程中生成的各种文件、数据库和运行记录。

---

## 🔒 隐私与版本控制规则

> **重要提示**：本目录下除各子目录的 `.gitkeep` 占位文件及公开测试样例外，**所有生成的最终文件与个人数据均已被 `.gitignore` 排除在版本库之外**。
> 
> 导出的 Word / PDF 简历含有个人私密信息，生成的面试录音或打分记录亦属于个人隐私，收集的目标岗位原始文本也可能包含敏感商业或薪资信息，绝不会被意外推送到 GitHub 等公共代码仓库。

---

## 📂 存储子目录划分

| 目录/文件 | 用途与生成物 | 隐私保护状态 |
| :--- | :--- | :---: |
| `resumes/` | 模块 0 生成的各版本 Word 与 PDF 简历成品（如 `resume_default.docx`、`resume_default.pdf`）。 | 🔒 严格忽略 |
| `radar_reports/` | 模块 2 定期扫描后生成的岗位深度评估与投递决策战略简报（Markdown 格式）。 | 🔒 严格忽略 |
| `raw_jds/` | 模块 2 机会雷达待扫描的目标岗位原始文本（保留 01/02/03 样例供体验）。 | 🔒 私人 JD 严格忽略 |
| `interview_logs/` | 模块 5 AI 模拟面试问答的对话全景文本，以及最终输出的《复盘体检报告》。 | 🔒 严格忽略 |
| `tracker.db*` | 模块 6 求职投递看板的本地轻量 SQLite 数据库及日志文件。 | 🔒 严格忽略 |
| `exports/` | 一键定制交付综合物料战报（含岗位专属定制自荐信、开源补强方案与交付清单）。 | 🔒 严格忽略 |
