# 🖼️ config/assets/ 用户多媒体资源目录

本文件夹专门用于存放与求职者个人相关的静态多媒体资源。

### 推荐放置的文件：
1. `avatar.png` 或 `avatar.jpg`：个人标准寸照/职业正装照（用于支持个人照片的简历模板）。
2. `school_logo.png`：毕业院校的校徽或矢量 Logo（透明底 PNG 最佳）。
3. 个人作品或系统架构图截图（如有需要附在作品集或长版简历中）。

### 命名规范建议：
- 照片请命名为 `avatar.png` 或 `avatar.jpg`。
- 校徽请命名为 `school_logo.png`。
- 本目录下的真实文件已被 `.gitignore` 保护，不会被上传至版本库。
