# 📋 skills/application_tracker/：模块 4 求职投递看板与时间线日程

## 🎯 业务定位与解决痛点
- **解决痛点**：
  - 秋招/春招旺季，应届生往往投递了 50~100+ 家公司，用普通记事本容易记混各家网申状态；
  - 经常搞错笔试时间、面试预约冲突、不知道某家公司目前处于初试还是复试阶段。
- **本模块职责**：
  - 基于本地轻量数据库（SQLite），管理求职全流程的投递生命周期；
  - 记录企业名称、投递岗位、投递日期、当前状态、笔试/面试日程、薪资待遇预期与跟进备注；
  - 联动 `job_radar` 和 `jd_matcher`，每次针对特定岗位生成简历时自动提示归档进入投递看板。

---

## 📊 投递阶段流转状态
```text
[已选定/待投] ──> [网申已投递] ──> [测评/笔试中] ──> [初试/一面] ──> [复试/终面] ──> [HR面/待发Offer] ──> [已获Offer / 流程终止]
```

## 📥 输入与输出契约
- **输入**：投递事件数据（企业、岗位、时间、状态等）。
- **输出**：投递统计概览（投递总数、面试转化率、近期待办日程）。数据落盘于 `storage/tracker.db`。
